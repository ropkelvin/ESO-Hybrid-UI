ESO Hybrid UI 3.4.0

AI-assisted development: AI tools contributed to portions of this addon's code and documentation. The maintainer is responsible for reviewing changes, validating behavior in ESO, and maintaining the addon.

This add-on is not created by, affiliated with or sponsored by ZeniMax Media Inc. or its affiliates.

WHAT IT DOES
Keeps ESO's native Gamepad Mode active and optionally applies a keyboard-style appearance to selected gameplay HUD elements. Controller input, configured gamepad bindings, menus, scenes, dialogs, trade, resurrection, player interaction, utility wheels, inventory and world-map routing remain native ESO behavior.

This release removes platform spoofing, temporary platform-setting flips, global dialog interception, custom player-interaction wheel routing and map-scene overrides. Action-bar labels use ESO's native keybinding display functions; ultimate controls remain native ESO controls.

REQUIREMENTS
- The Elder Scrolls Online PC/Mac client.
- LibAddonMenu-2.0 version 43 or newer, installed separately.
- Optional: LibGamepadOptions AddOnVersion 7 or newer for a dedicated ESO Hybrid UI category in the native gamepad Options menu.
- ESO Gamepad Mode should be set to On for controller-first behavior.

INSTALLATION
Extract the ESOHybridUI folder into Documents/Elder Scrolls Online/live/AddOns.
Do not install this ZIP inside another folder. Enable ESO Hybrid UI in the in-game Add-Ons menu. The keyboard settings panel remains available through LibAddonMenu-2.0.

SAFETY / SCOPE
This addon changes HUD presentation and keybind prompt display only. It does not replace ESO's input, scene, dialog, trade, resurrection or interaction handlers. It does not automate combat, send mail, attach gold, trade, or execute gameplay actions on the player's behalf. The optional donation control only opens a mail draft; the player decides whether to send it and whether to attach gold.
